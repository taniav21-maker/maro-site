# M.A.R.O. — авторская бижутерия ручной работы

Бренд-сайт ювелирной мастерской M.A.R.O. Однофайловый лендинг на чистом
HTML/CSS/JS — без фреймворков и сборки.

## Ссылки

- Живой сайт (GitHub Pages): https://taniav21-maker.github.io/maro-site/
- Кейс проекта (витрина): https://github.com/taniav21-maker/proekt-maro
- Трекер заказов «мастер–клиент»: https://github.com/taniav21-maker/maro-tracker

## Структура

```
index.html   # разметка сайта
styles.css   # стили по брендбуку (шампань #FBDDB1, изумруд #073D37)
script.js    # интерактив
img/         # фотографии изделий
```

## Запуск локально

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8000
```

Дизайн и код — вайб-кодингом под ключ.
